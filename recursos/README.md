# Recursos gratuitos

Esta carpeta es para las cosas que el proyecto vaya soltando gratis: guías prácticas, plantillas y pequeñas herramientas que primero se usan por dentro y, cuando están lo bastante pulidas como para servirle a cualquiera, se publican aquí.

El criterio es el mismo que con los productos: solo se sube lo que ya se ha usado de verdad en un negocio. Nada de PDF de relleno.

**De momento no hay ninguno publicado.** Los primeros están en preparación; cuando caiga el primero, esta página lo dirá.

Para enterarse de cuándo llegan: [Instagram](https://instagram.com/sole.hand) o la propia web, [solehand.com](https://solehand.com).
